Privacy Policy & Terms of Service

Last updated: June 2026

This document describes how personal data is collected, used, and protected when using the application Latilearn (the “App”).

This policy applies to all services operated under the domain latilearn.kwako.nl and its API services.

1. Data Controller

The data controller responsible for processing personal data is:

  • Name: Arthur Kwak
  • Contact: tureluurtje.1@gmail.com

2. Data We Collect

The App stores and processes the following categories of data:

2.1 Account Data

  • Email address
  • Username
  • Password (securely hashed, never stored in plain text)
  • School grade (user-provided)

2.2 Learning Data

  • Word progress (linked to user account)
  • Leitner system cards (user ID + unique word ID)
  • Card stability values
  • Review history (correct/incorrect answers, timestamps)
  • Total words learned
  • Streak tracking

2.3 Technical Data

  • IP address (for security and abuse prevention)
  • Backend-generated crash logs

No analytics SDKs, advertising networks, or third-party tracking tools are used.

3. Data Storage

All data is stored securely in a PostgreSQL database operated by the service backend hosted at:

latilearn.kwako.nl

No Redis, external analytics providers, or cross-app tracking systems are used.

4. Purpose of Data Processing

Data is used strictly for:

  • Providing user accounts and authentication
  • Tracking learning progress in the Leitner system
  • Storing and syncing vocabulary performance
  • Improving reliability and security of the service

5. Data Sharing

We do not sell, rent, or share personal data with third parties.

Data is only processed internally by the application backend.

6. Data Retention

User data is stored until the user deletes their account. After deletion, all associated data is permanently removed from the database.

7. Account Deletion

Users can delete their account directly within the application. Account deletion results in:

  • Removal of account credentials
  • Deletion of all learning data (cards, progress, streaks)
  • Removal of associated identifiers

8. Security

Passwords are securely hashed before storage. All communication between client and server uses HTTPS encryption.

9. User Rights (GDPR)

Users located in the European Union have the right to:

  • Access their personal data
  • Request correction of inaccurate data
  • Request deletion of their data
  • Withdraw consent where applicable

10. Children’s Privacy

The App may be used in educational contexts but does not knowingly collect data from children without appropriate user consent via school or guardian authorization.

11. Changes to This Policy

This Privacy Policy may be updated from time to time. Continued use of the App constitutes acceptance of the updated policy.
